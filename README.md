# watchhouse-advisory-test

GitHub Pages site for Watchhouse Advisory.

## Updating the site

Replace `index.html` with your HTML file and push to `main`. The [Deploy to GitHub Pages](.github/workflows/deploy-pages.yml) workflow publishes it automatically.

## First-time setup

After merging this PR, enable GitHub Pages in the repository settings:

1. Go to **Settings → Pages**
2. Under **Source**, select **GitHub Actions**
3. The next push to `main` will deploy the site
